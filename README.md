# EWARI

EWARI is a personal styling inspiration PWA rooted in Nigerian culture and built for a global audience.

## Product idea

EWARI learns your taste, recommends complete outfit combinations for different occasions, visualises each look on a consistent mannequin, and lets you swap individual pieces. EWARI does not sell clothing. It helps you decide what to look for when shopping elsewhere.

## Stack

- Next.js 16
- React 19
- TypeScript
- Iconsax
- Supabase-ready data layer
- PWA manifest and service worker

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Environment

Copy `.env.example` to `.env.local` when the Supabase project is ready.

## Current milestone

The first milestone covers onboarding, personalised recommendations, occasion browsing, outfit details, item swapping, saving and Style Me.
